# 🎮 Tic-Tac-Toe Game (Pygame)

A clean, responsive 2D Tic-Tac-Toe game built in Python using Pygame.

## 🚀 Features
- Interactive 2D graphical user interface.
- Turn-based two-player gameplay (X vs. O).
- Built-in win detection for rows, columns, and diagonals.

## 🛠️ Requirements
- Python 3.x
- Pygame (`pip install pygame`)
